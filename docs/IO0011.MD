# IO0011. Replace StreamReader string constructor overload with stream based overload using a stream from IFileSystem.FileStream for improved testability

| Topic    | Value
| :--      | :--
| Id       | IO0011
| Severity | Warning
| Enabled  | True
| Category | System.IO.Abstractions

## Description

Replace StreamReader string constructor overload with stream based overload using a stream from IFileSystem.FileStream for improved testability

## Code with Diagnostic

``` csharp
using System.IO;
using System.IO.Abstractions;

namespace SomeNameSpace
{
	public class WithOutFileSystem
	{
		private readonly IFileSystem _fileSystem;

		public WithOutFileSystem(IFileSystem fileSystem)
		{
			_fileSystem = fileSystem;
		}

		public void SomeMethod()
		{
			const string filePath = "C:\\temp.txt";

			using (var fstream = new FileStream(filePath, FileMode.OpenOrCreate))
			{
			}
		}
	}
}
```

## Code with Fix

``` csharp
using System.IO;
using System.IO.Abstractions;

namespace SomeNameSpace
{
	public class WithOutFileSystem
	{
		private readonly IFileSystem _fileSystem;

		public WithOutFileSystem(IFileSystem fileSystem)
		{
			_fileSystem = fileSystem;
		}

		public void SomeMethod()
		{
			const string filePath = "C:\\temp.txt";

			using (var fstream = _fileSystem.FileStream.New(filePath, FileMode.OpenOrCreate))
			{
			}
		}
	}
}
```
